# 🏫 Sistema de Gerenciamento de Alunos

## 📌 Sobre o projeto

Este repositório documenta uma experiência prática envolvendo a **configuração, monitoramento e suporte de um sistema de gerenciamento de alunos utilizado por uma escola de dança**.

O projeto apresenta as atividades realizadas, os procedimentos utilizados e os conhecimentos desenvolvidos durante a utilização e acompanhamento do sistema.

> 🔒 **Privacidade:** informações pessoais, dados de alunos e informações confidenciais da instituição não são disponibilizados neste repositório.

---

## 🎯 Objetivo

Contribuir para o funcionamento adequado do sistema utilizado pela escola, realizando atividades de configuração, acompanhamento, identificação de problemas e suporte aos usuários.

---

## 👨‍💻 Minha atuação

Durante a utilização do sistema, foram realizadas atividades relacionadas a:

* Configuração do sistema;
* Organização das informações;
* Monitoramento do funcionamento;
* Identificação de problemas;
* Análise de situações apresentadas pelos usuários;
* Suporte aos usuários;
* Verificação do funcionamento após ajustes ou correções.

---
