# ⚙️ Configuração do Sistema

## 📌 Objetivo

Documentar as atividades realizadas durante a configuração do sistema de gerenciamento de alunos utilizado pela escola de dança.

## 🛠️ Atividades realizadas

Nesta etapa foram realizadas atividades relacionadas à preparação e configuração do sistema para sua utilização.

### Atividades

* Configuração do sistema;
* Organização das informações;
* Ajustes necessários para utilização;
* Verificação das funcionalidades;
* Testes de funcionamento.
